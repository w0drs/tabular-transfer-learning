# Tabular transfer learning
**Transfer Learning** (перенос обучения) — одна из ключещих парадигм современного машинного обучения. Она успешно применяется в компьютерном зрении и NLP, позволяя переносить знания с больших датасетов на малые. Однако в **табличных данных** такая практика остаётся малоизученной.
